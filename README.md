# 月日（つきひ）— 最小構成モック

月経前障害（PMS・PMDD）の受診判断を支援する記録の仕組み。SPLアカデミー AY26/27 の検討用の試作。

## これは何か

月経前後の不調を毎月繰り返しながら受診していない人が、自分の不調が治療の対象になりうるかを判断し、受診するかどうかを決めるための手がかりを得る。それだけを行う。

診断はしない。記録やウェアラブルのデータから PMS・PMDD を判定しない。

## なぜ最小構成なのか

診断側が求める記録（DRSP、2周期の毎日の記録）と、受診前の人が実際にできる記録のあいだには段差がある。一気に埋めようとすると続かない。そこで、受診前は「つらかった日だけ」、受診が決まってから毎日の記録に切り替える二段構えにした。

## 画面

| 画面 | 入力 | 役割 |
|---|---|---|
| ホーム | 今日の調子（3択・1タップ）、月経開始日（ボタン1つ） | 記録。つけたい日だけ |
| ふりかえり | なし | 2周期を月経開始日で重ね、つらい日の位相を見せる |
| 受診の準備 | なし | 医師に見せる1枚。DRSP への橋渡し |
| 1分の確認 | 4問 | 記録に進むかどうかの入口 |

ふりかえりのデータは、動きを見せるための例である。

## 設計の根拠

PSST と DRSP を同一集団で比較した研究では、両者の判定は一致せず（Kappa 0.12）、PSST の感度 79%、特異度 33.3% だった（Henz 2018, doi:10.1055/s-0037-1608672）。質問票は診断ではなく入口として使う。この二つの数字は「1分の確認」の結果画面にそのまま書いてある。

質問票は、日本で開発され心理測定が確かめられている PSQ に差し替えるのが筋である（Takeda 2020, doi:10.2147/IJWH.S269392）。モックの4問は仮のもの。

HRV は画面から外した。月経周期の位相推定には見込みがあるが、症状の判定に使った報告は群間比較にとどまる（Brown 2024, doi:10.3389/fpsyt.2024.1448914）。
